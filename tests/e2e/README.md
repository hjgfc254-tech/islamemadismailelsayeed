# End-to-end tests

Reserved for browser-level journey tests. Existing tests are Node-based static/VM tests; no browser runner is configured.

## Manual browser scripts
- `reports.browser.js` — optional Playwright/Chromium journey for the admin Reports page at 1280/768/390px (report/period/category switching, empty state, CSV download, export log, keyboard, overflow, JS errors, external requests). It is **not** run by `npm test` and Playwright is **not** a project dependency: it needs a globally available Playwright + Chromium and a static server (`python3 -m http.server 8099` from the project root, then `node tests/e2e/reports.browser.js http://127.0.0.1:8099`). Last run: 2026-11-09, all checks passed.
- `audit-log.browser.js` — same setup; checks the read-only audit-log page (search, details dialog, Escape/focus return, no write/export buttons, overflow, JS errors). Last run: 2026-11-09, all checks passed.
- `security.browser.js` — same setup; checks the security page (tabs, read-only login attempts, escalate needs a reason, simulated action + local log, current session cannot be ended, overflow, JS errors, external requests). Last run: 2026-11-09, all checks passed.
- `system-settings.browser.js` — same setup; checks the settings page (validation + aria-invalid + focus, review dialog, reason required, simulated save + log, Escape/focus return, restore defaults, Enter, overflow, JS errors, external requests). Last run: 2026-11-09, all checks passed.
