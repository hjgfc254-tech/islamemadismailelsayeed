## Known limitations

- Provider is the standalone frontend demo (`apps/provider/`). The legacy bridge (`portal-compat.js`, `provider-workspace.js`) was removed on 2026-11-14 after capability migration; Admin console operations live in `apps/admin/pages/marketplace.page.js`.
- Marketplace writes in all three apps go through the mock API adapters (`services/*-api.js`); `MP` is the local read model.
- Legacy global scripts remain; no ES-module conversion was attempted because it would be a higher-risk behavioral rewrite.
- Direct route rewrites depend on hosting support for `_redirects`.
- Browser console, actual offline behavior, IndexedDB persistence across deployment and mobile browser rendering were not validated in a real browser in this environment.
