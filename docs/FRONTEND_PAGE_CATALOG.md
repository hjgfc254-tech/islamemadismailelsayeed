### قواعد فحص صفحات العميل
- تأكد أن التنقل لا يفقد بيانات Wizard أو اختيارات البحث دون قصد.
- اختبر النصوص العربية الطويلة، أسماء المناطق، العناوين، وغياب الصور.
- تحقق من أن الحالات المالية/التقييمات/التوافر معروضة كبيانات تجريبية عندما تكون كذلك.
- اختبر الرجوع وإعادة التحميل وروابط الصفحات؛ لا تفترض دعم deep-link قبل التحقق.

### مواصفات shell الإدارة عند بدء تنفيذه
- Sidebar/Drawer متجاوب، Header، Breadcrumbs، عنوان صفحة ووصف، actions area، content container.
- حالات collapse/expanded للـ sidebar وحفظها محليًا عند الحاجة.
- mobile navigation لا يضغط محتوى الصفحة ولا يغطيه بشكل غير قابل للإغلاق.
- كل عنصر قائمة يطابق route/page موجودة فعلًا؛ الروابط غير الجاهزة تظهر disabled أو غير منشورة، لا روابط ميتة.
- لا تعرض UI الصلاحيات على أنه enforce؛ هي محاكاة presentation فقط.
