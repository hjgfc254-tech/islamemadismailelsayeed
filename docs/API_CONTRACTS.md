# API Contracts

No HTTP API is present in this package. Files named `*-api.js` are placeholders only. Before implementing them, define request/response schemas, authentication requirements, error formats, idempotency rules, pagination, rate limits and versioning. Existing local MP/CAT contracts are not backend API contracts.
